# 🎭 多角色舞台系统

> 舞台 = 一群角色共享同一个叙事场景。你创建多个角色卡，它们会在同一段命运中互相回应、交锋、并肩。

## 🏗 舞台目录约定

舞台的组织方式与单角色契约完全一致，只是把多个角色卡放进**一个子目录**：

- **舞台 = 契约根目录下的「一层子目录」**，文件夹名 = 舞台名（如 `Camlann/`）
- 舞台内含 **N 份平级 `.meph` 角色卡**（如 `Arthur.meph` / `Mordred.meph`）
- 每个角色各自的运行时存档为 `舞台/角色名.child.meph`（引擎自动生成，无需手写）
- **不做深层嵌套**：舞台目录内只放平级角色卡，不支持子目录
  （避免与「单角色子版基于 `.` 分段推导」混淆）

```text
契约目录/
├── faust.meph          ← 单角色契约（不受影响）
├── dantes.meph
└── Camlann/            ← 舞台 = 一层子目录
    ├── Arthur.meph
    ├── Mordred.meph
    ├── Arthur.child.meph   ← 自动生成的存档（不用管）
    └── Mordred.child.meph
```

## 🚀 如何创建舞台

1. 在契约目录下新建一个文件夹（如 `我的舞台/`）
2. 将每个角色写成一个 `.meph` 契约文件，放入该文件夹
3. 刷新首页 → 「多角色舞台」区自动出现该舞台卡片

> 💡 也可以使用首页「导入」功能解压别人分享的舞台 ZIP（舞台目录会原样还原）。

## 📜 角色卡格式

舞台内的角色卡**复用完整契约语法**（区块、状态、规则、骰子、记忆等见 [契约语法参考](contract-syntax.md)），额外约定：

- **公共世界观**：整个舞台的【世界观】取**第一个角色卡**（按文件名字典序排在最前的那份）
- 每个角色的【锚点】【状态】【记忆】【规则】**独立运行**，互不混淆：
  - 亚瑟王触发状态变更，不会影响莫德雷德的状态
  - 每个角色只看到自己的记忆，看不到别人的过往

## ⚙️ 叙事机制

多角色舞台的每一轮生成：

1. **每位角色各自运行规则引擎**（状态变更、记忆注入、骰子判定独立隔离）
2. **单次 LLM 调用**：所有角色共享同一段命运指引
3. **输出为「全景叙事流」**：一段流畅的第三人称小说，自然提及有戏份的角色
   - 有戏份的角色在同一段文字中互动（对话 / 动作 / 交锋）
   - 未被提及的角色 = 本回无戏份，不强行出场
4. **后端按「提及归属」** 把整篇叙述映射到被提到的角色
5. **兜底降级**：输出既无法分节也无法按提及归位时，逐角色独立调用生成，保证每人都能回应

> 骰子判定（`roll(1d100)` 等）同样支持：触发时以系统消息「命运结算」卡片展示。

## 💾 存档机制

- **独立存档**：每个角色各自保存到 `舞台/角色名.child.meph`
- **恢复**：进入舞台时按角色各自恢复存档；「重新开始」则回母版开局
- **删除角色卡**：级联删除该角色的 `.child.meph` 存档
- **只重置进度**：可选「删除存档」仅删除 `.child.meph`，保留母版角色卡

## 📂 内置舞台示例

| 舞台                       | 角色                           | 场景                           |
| -------------------------- | ------------------------------ | ------------------------------ |
| `Camlann/`（卡美洛之陨）   | `Arthur.meph` × `Mordred.meph` | 亚瑟王与莫德雷德的父子终局之战 |
| `Kurukshetra/`（俱卢之野） | `Arjuna.meph` × `Karna.meph`   | 摩诃婆罗多战场双雄的对决       |

## ⚠️ 注意事项

- **角色名唯一**：舞台内各位角色的【角色名】应互不相同（互斥组、记忆注入、气泡着色都按角色名隔离）
- **单卡损坏不拖垮舞台**：某个角色卡解析失败时，该角色被跳过，其余角色正常进入
- **存档不会冒充角色**：`.child.meph` 已被自动过滤，不会在首页显示为额外角色
