# 🧠 记忆系统

> 记忆系统让 AI 叙事**跨越单次对话**保持一致性：它自动提取关键事件、去重、压缩，
> 并以「记忆」形式注入系统提示词，塑造角色的长期连续性。

## 1. 记忆的生命周期

```text
对话进行中（命运 ↔ 角色）
    ↓
每 3 轮触发记忆提取（maybeExtract）
    ↓
从最近 20 条消息提取 2-5 条核心事件摘要
    ↓
去重（与现有记忆比对，跳过重复）
    ↓
超过 30 条？ → 压缩（旧记忆摘要 + 保留最近 5 条）
    ↓
记忆列表注入系统提示词
```

## 2. 提取时机

- 每 **3** 轮对话提取一次（由 `extractInterval = 3` 控制）
- 轮数按「命运（玩家）」消息计数
- 提取窗口为最近的 **20** 条消息（`extractWindow = 10` × 2，含命运与角色消息）

## 3. 提取规则

MemoryManager 通过 LLM 提示词约束提取行为：

1. 提取 **2-5 条**对角色有重大影响的核心事件，覆盖整段剧情推进
2. 回顾整段对话的事件链，而非只取最后一句话
3. 每条摘要 20-60 个字，保留关键人物、地点、动作与信息
4. 忽略日常寒暄与无意义对话
5. 与现有记忆重复的不再提取
6. **禁止修改/重复角色的核心设定**（角色名、锚点、状态值等）
7. 输出格式：每行一条，以 `- ` 开头

## 4. 去重与压缩

### 去重

- 新提取的记忆与现有记忆逐条比对（按内容去重）
- 完全重复的条目被丢弃

### 压缩（超限触发）

- 记忆总数上限 **30 条**（`maxLimit`）
- 超过上限时触发压缩：
  - 旧记忆（除最近 5 条外）交给 LLM 压缩成不超过 5 条摘要
  - **保留最近 5 条**（`compressRetain`）原文
  - 压缩后的摘要 + 最近原文合并为新的记忆列表

## 5. 记忆如何影响叙事

- 记忆列表作为系统提示词的一部分注入，为 LLM 提供「这个角色经历了什么」的长期上下文
- 配合契约的【记忆】区块（初始记忆）与运行时动态提取的记忆，共同构建角色一致性

## 6. 失败降级策略

| 场景             | 行为                                  |
| ---------------- | ------------------------------------- |
| LLM 调用失败     | 静默跳过本次提取/压缩，保留原记忆列表 |
| 提取结果为空     | 返回原记忆列表                        |
| 提取结果全部重复 | 返回原记忆列表                        |
| 压缩结果为空     | 保留原记忆列表                        |

> 记忆系统**永远不会**因 LLM 异常而中断叙事主流程。

## 7. 相关代码与常量

| 项                | 值  | 说明                    |
| ----------------- | --- | ----------------------- |
| `extractInterval` | 3   | 每 N 轮提取一次         |
| `extractWindow`   | 10  | 提取窗口（× 2 = 20 条） |
| `maxLimit`        | 30  | 记忆总数上限            |
| `compressRetain`  | 5   | 压缩时保留的最近条数    |

核心实现：`lib/services/memory/memory_manager.dart`
